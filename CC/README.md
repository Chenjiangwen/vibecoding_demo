# 🤖 抬杠机器人 - 使用指南

## 项目简介

这是一个简单易用的前端网页应用,用户输入观点后,AI会自动生成3个反方观点和1个幽默回应句。界面简洁美观,无需复杂配置。

## 功能特点

✅ 简洁直观的用户界面
✅ 输入观点,一键获取反方论证
✅ AI生成3个反方观点
✅ 附带幽默回应,增加趣味性
✅ 响应式设计,支持手机、平板、电脑
✅ 完善的错误提示和加载动画
✅ 无需安装任何软件,浏览器直接打开

## 快速开始

### 方法一:本地直接打开(最简单)

1. 下载项目文件到你的电脑
2. 找到 `index.html` 文件
3. 双击打开,自动使用浏览器运行
4. 开始使用!

### 方法二:使用本地服务器(推荐)

**为什么需要本地服务器?**
由于浏览器的安全限制,直接打开HTML文件可能无法正常调用API接口。使用本地服务器可以避免跨域问题。

#### 使用Python启动(适合Mac/Linux用户)

```bash
# 进入项目目录
cd /Users/chenjiangwen/code/Not_troll_robot/CC

# Python 3 用户
python3 -m http.server 8000

# Python 2 用户
python -m SimpleHTTPServer 8000
```

然后在浏览器中访问:
**http://localhost:8000**

#### 使用Node.js启动(适合有Node环境的用户)

```bash
# 安装简单的HTTP服务器(只需要运行一次)
npm install -g http-server

# 进入项目目录并启动
cd /Users/chenjiangwen/code/Not_troll_robot/CC
http-server -p 8000
```

然后在浏览器中访问:
**http://localhost:8000**

#### 使用VS Code启动(最方便)

1. 用VS Code打开项目文件夹
2. 安装 "Live Server" 插件
3. 右键点击 `index.html`,选择 "Open with Live Server"
4. 自动在浏览器打开

## 配置API接口

**重要提示:** 在使用前,你需要将代码中的API地址替换为真实地址。

1. 用任何文本编辑器打开 `index.html` 文件
2. 找到第 227 行左右的代码:

```javascript
const response = await fetch('你的API地址', {
```

3. 将 `'你的API地址'` 替换为实际的API地址,例如:

```javascript
const response = await fetch('https://your-api.com/counter-argue', {
```

4. 保存文件
5. 刷新浏览器页面

## 使用方法

### 步骤1:输入观点

在文本框中输入你的观点,例如:
- "多喝热水对身体好"
- "早睡早起是好习惯"
- "运动有益健康"

点击"开始抬杠"按钮,或者按 `Ctrl+Enter`(Mac用户按 `Cmd+Enter`)

### 步骤3:查看结果

等待几秒钟,AI会返回:
- **你的观点**: 显示你刚才输入的内容
- **反方观点**: 3个不同角度的反方论证
- **幽默回应**: 1个轻松幽默的调侃句

## API接口说明

### 请求格式

```http
POST 你的API地址
Content-Type: application/json

{
  "opinion": "用户输入的观点"
}
```

### 响应格式

AI接口应该返回以下格式的JSON数据:

```json
{
  "counter_opinions": [
    "反方观点1",
    "反方观点2",
    "反方观点3"
  ],
  "humor_response": "幽默回应句"
}
```

### 示例

**请求:**
```json
{
  "opinion": "多喝热水对身体好"
}
```

**响应:**
```json
{
  "counter_opinions": [
    "喝太多水可能导致水中毒,稀释血液中的钠含量",
    "热水温度过高会损伤食道黏膜,增加食道癌风险",
    "频繁喝水会增加肾脏负担,影响肾功能"
  ],
  "humor_response": "直男万能回复'多喝热水'终于遇到对手了!"
}
```

## 常见问题

### Q1: 点击按钮后没有反应?

**A:** 请检查:
1. 是否已配置正确的API地址
2. 是否使用本地服务器运行(而不是直接打开HTML)
3. 打开浏览器的开发者工具(F12),查看Console控制台是否有错误信息
4. 检查网络连接是否正常

### Q2: 显示"服务器错误"?

**A:** 可能原因:
1. API接口地址不正确
2. API服务未启动
3. 网络连接问题
4. API接口返回了错误状态码

### Q3: 显示"返回数据格式错误"?

**A:** API返回的数据格式不符合要求,请确保:
1. 返回的是JSON格式
2. 包含 `counter_opinions` 数组,且有3个元素
3. 包含 `humor_response` 字符串

### Q4: 如何在手机上使用?

**A:**
1. 确保手机和电脑在同一个WiFi网络
2. 启动本地服务器
3. 找到电脑的IP地址(Windows输入`ipconfig`,Mac/Linux输入`ifconfig`)
4. 在手机浏览器访问: `http://电脑IP:8000`
5. 例如: `http://192.168.1.100:8000`

### Q5: 如何修改页面样式?

**A:**
1. 打开 `index.html` 文件
2. 找到 `<style>` 标签内的CSS代码(第7-200行左右)
3. 修改颜色、字体、间距等样式
4. 保存后刷新浏览器查看效果
